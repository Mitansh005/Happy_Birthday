# Birthday site for Yashu

Everything lives in `index.html`. Photos go in the `photos/` folder.

## Add photos
1. Drop her photos into `photos/` and name them `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`
2. Portrait (tall) photos look best — around 800x1100px
3. Keep each file under ~500 KB so it loads fast
4. If you want different filenames or more than 4, edit the `photos` array in the CONFIG block near the bottom of `index.html`

## Edit the words
Open `index.html`, scroll to the `CONFIG` block (it's marked). Change the name, the letter, the notes, the captions. Nothing else needs touching.

## Put it live on GitHub Pages
1. Make a new public repo (e.g. `happy-birthday-yashu`)
2. Upload `index.html` and the `photos` folder
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root` → Save
4. Wait ~1 minute. Your link: `https://<your-username>.github.io/<repo-name>/`
